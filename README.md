# Creación Digital

Landing estática (HTML + CSS en un solo archivo). Sitio: https://creaciondigital.somoswilsonymaria.site

## Publicar en Cloudflare Pages
1. Sube esta carpeta a un repositorio de GitHub (la raíz del repo debe contener `index.html`).
2. Cloudflare > Workers y Pages > Crear > Pages > Conectar con Git > elige el repositorio.
3. Framework preset: None. Build command: (vacío). Build output directory: `/`.
4. Guardar y desplegar. Luego, en Custom domains, agrega `creaciondigital.somoswilsonymaria.site`.
5. Registra el sitio en Google Search Console y envía `https://creaciondigital.somoswilsonymaria.site/sitemap.xml`.
